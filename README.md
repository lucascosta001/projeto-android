# Projeto Android — Interface Web

Projeto desenvolvido durante os estudos de **HTML5 e CSS3**, inspirado no capítulo 17 do curso de desenvolvimento web.

## 🎯 Objetivo
Praticar a construção de uma página web completa, trabalhando estrutura, estilização e organização visual.

## 🛠️ Tecnologias
- HTML5
- CSS3

## 📚 Conceitos praticados
- Estrutura semântica
- Layout responsivo
- Organização de conteúdo
- Estilização com CSS

## 🚀 Como visualizar
Abra o arquivo principal HTML em um navegador ou utilize uma extensão de servidor local no VS Code.
